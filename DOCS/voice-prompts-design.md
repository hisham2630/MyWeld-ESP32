# Boot & BLE Voice Prompts

## Summary

Four TTS spoken prompts give users audible feedback during boot and BLE pairing:

| Prompt | Trigger |
|--------|---------|
| Welcome | Splash phase 1 (all display variants) |
| Ready to pair | Splash done **and** BLE advertising active |
| Pairing | 1.5 s after BLE connect if still unauthenticated; replay on wrong PIN |
| Device has been connected | PIN auth success (manual or stored PIN auto-auth) |

Voice plays first; existing startup melody and BLE connect chime still follow.

## Assets

- Generated by `scripts/generate_voice_prompts.py` (edge-tts → ffmpeg → `embed_wav.py`)
- Embedded as `voice_welcome`, `voice_ready_to_pair`, `voice_pairing`, `voice_connected`
- Format: 44100 Hz mono s16 PCM (~648 KB total flash)

## Modules

- `boot_audio.c` — coordinates splash + BLE readiness for "ready to pair"
- `audio_play_*()` — I2S PCM on speaker boards; tone fallbacks on buzzer boards
- `ble_serial.c` — pairing timer avoids prompt on fast auto-reconnect

## Regenerating clips

```bash
python scripts/generate_voice_prompts.py
```
